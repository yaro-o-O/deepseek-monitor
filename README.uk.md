## ✨ Навіщо DeepSeek Monitor?

Офіційна платформа DeepSeek розкидає баланс і використання по різних сторінках, не має кнопки оновлення і не дає розбивки за ключами. **DeepSeek Monitor** збирає все на одній компактній панелі:

- 💰 Баланс як на долоні, з **автооновленням** під час роботи
- 📊 Токени, влучання кешу та витрати за моделями **V4 Flash і V4 Pro**
- 🔑 Кількість запитів, токени, влучання кешу й витрати **за кожним API-ключем** — плюс підсумок за всіма ключами
- 💱 Витрати **за кожною валютою** окремо (`¥… + $…`), ніколи не змішуються
- 📈 7-денний графік тренду з деталізацією за днями
- 🪟 Живе в **системному треї** — завжди під рукою, не заважає

## 🚀 Можливості

- **Моніторинг балансу в реальному часі** — запитуйте баланс акаунта DeepSeek одним кліком; доступна сума та стан акаунта
- **Статистика за двома моделями** — окремо токени, влучання кешу та витрати для V4 Flash і V4 Pro
- **Розбивка за API-ключами** — картка «За API-ключами» ділить запити, токени, влучання кешу й витрати вибраного місяця між усіма ключами, з офіційного експорту використання (автозавантаження з токеном або імпорт ZIP/CSV). Доступні останні 12 місяців
- **Підсумок за всіма ключами** — вибір у картці балансу також пропонує «Усі ключі», який об'єднує всі ключі; це типовий вигляд, і він керує показниками «Сьогодні», «Цього місяця», рядками моделей, графіком і деталями
- **Витрати у кількох валютах** — якщо акаунт оплачується в кількох валютах, витрати показуються за кожною окремо (напр. `¥12.45 + $0.76`) і ніколи не конвертуються та не додаються
- **7-денний графік тренду** — використання токенів за останні 7 днів із розбивкою на влучання / промах / вихід
- **Деталізація використання** — клік на рядок моделі відкриває витрати токенів і кількість запитів за днями
- **Сповіщення про баланс** — системне сповіщення, коли баланс падає нижче заданого порогу (один раз на поріг, для кожного акаунта)
- **Кілька акаунтів** — керуйте кількома акаунтами DeepSeek і перемикайтеся в Налаштуваннях
- **Інтерфейс англійською, китайською та українською** — виберіть мову інтерфейсу в Налаштуваннях; вибір зберігається
- **Шифрування даних доступу** — API-ключі та токени використання шифруються через системний ключницю (Electron `safeStorage`)
- **Автооновлення в застосунку** — нові релізи виявляються й встановлюються просто з застосунку
- **Автооновлення даних** — інтервали 1 хв / 5 хв / 30 хв / 1 год
- **Автозапуск** — підтримується у Windows і macOS
- **Системний трей** — закриття чи згортання ховає в трей; викликайте будь-коли
- **Режим закріпленого віджета** — закріпіть вікно поверх інших; при наведенні воно ховається або стає напівпрозорим (з наскрізними кліками, тож не заважає), і відновлюється, коли курсор відходить (керується й з меню трею)
- **Синхронізація токена одним кліком** — вбудоване вікно входу, яке автоматично захоплює токен використання

## 🔑 Використання за API-ключами

Живий API використання дає розбивку лише за моделями, тож дані за ключами беруться з офіційного **експорту використання** (`GET /api/v0/usage/export` — ZIP із `amount-*.csv` + `cost-*.csv`).

- **Автозавантаження** — якщо задано токен використання, експорт за поточний місяць завантажується та кешується (з коротким TTL). Кнопка ⟳ у картці «За API-ключами» примусово перезавантажує, а в списку можна вибрати інший місяць.
- **Ручний імпорт** — експортуйте файл із платформи DeepSeek і додайте його через **Імпорт файлу експорту (ZIP/CSV)**.
- **Усі ключі** — вибір у картці балансу об'єднує всі ключі; це типовий вигляд.
- **Гроші** надходять із `cost.csv` і розподіляються між ключами / моделями / днями за вагою використання, тож сума за ключами збігається з офіційним підсумком. Суми зберігаються **за кожною валютою** окремо.

API-ключі показуються лише замаскованими (`sk-abc…0def`); повне значення не залишає головний процес і не потрапляє в логи.

## 📦 Встановлення

### Варіант 1: Завантажити інсталятор (рекомендовано)

Візьміть найновіший інсталятор зі [сторінки релізів](https://github.com/yaro-o-O/deepseek-monitor/releases) — Node.js не потрібен.

### Варіант 2: Зібрати з коду

**Передумови:** [Node.js](https://nodejs.org/) ≥ 18 і npm (або yarn).

```bash
# Клонувати репозиторій
git clone https://github.com/yaro-o-O/deepseek-monitor.git
cd deepseek-monitor

# Встановити залежності
npm install

# Запустити в режимі розробки
npm start

# Або з інструментами розробника
npm start -- --dev
```

### Пакування

```bash
# Усі платформи
npm run build

# Windows (інсталятор NSIS)
npm run build:win

# macOS (образ DMG)
npm run build:mac

# Linux (AppImage)
npm run build:linux
```

Артефакти збірки з'являються в `dist/`.

## 🧭 Початок роботи

### Перше налаштування

1. Відкрийте застосунок і перейдіть у **Налаштування** (іконка ⚙)
2. **API Key**: вставте свій DeepSeek API Key (починається з `sk-`), натисніть «Перевірити й зберегти»
3. **Токен використання**:
   - **Варіант A (рекомендовано)**: натисніть «Синхронізувати через веб-вхід» — увійдіть у вікні, що відкриється, і токен захопиться автоматично
   - **Варіант B**: натисніть «Вставити токен вручну» — скопіюйте Bearer-токен із DevTools браузера

### Опис панелі

| Розділ | Опис |
|--------|------|
| Баланс акаунта | Загальний баланс і доступність активного акаунта (завжди на рівні акаунта) |
| Вибір API-ключа | Обмежує показники нижче одним ключем — або **Усі ключі** (типово) для всього акаунта |
| Сьогодні | Витрати за сьогодні (акаунт або вибраний ключ), за валютами |
| Цього місяця | Витрати з початку місяця (акаунт або вибраний ключ), за валютами |
| V4 Flash / V4 Pro | Токени, витрати та влучання кешу за місяць для моделі (акаунт або вибраний ключ) |
| За API-ключами | Запити, токени, влучання кешу та витрати кожного ключа за вибраний місяць, плюс підсумок за всіма |
| 7-денний тренд | Стовпчикова діаграма токенів (влучання / промах / вихід); клік на рядок моделі — деталі за днями |

### Автооновлення

Увімкніть «Автооновлення» в Налаштуваннях і виберіть інтервал — застосунок оновлюватиме баланс і дані використання за розкладом, разом із розбивкою за ключами.

## 🛠 Технології

- **Electron** — кросплатформний фреймворк для десктопних застосунків
- **Нативні HTTP/HTTPS** — прямий зв'язок з API DeepSeek, без сторонніх HTTP-клієнтів
- **Чистий фронтенд** — без UI-фреймворків, лише HTML/CSS/JavaScript
- **fflate** — розпаковує офіційний експорт використання в процесі
- **electron-builder** — пакування та розповсюдження

## 🔌 API-ендпоінти

Застосунок використовує такі офіційні ендпоінти DeepSeek:

| Ендпоінт | Призначення | Авторизація |
|----------|-------------|-------------|
| `GET /user/balance` | Баланс акаунта | API Key |
| `GET /models` | Доступні моделі | API Key |
| `GET /api/v0/usage/amount` | Статистика використання | Usage Token |
| `GET /api/v0/usage/cost` | Статистика витрат | Usage Token |
| `GET /api/v0/usage/export` | Місячний експорт використання (ZIP із розбивкою за ключами) | Usage Token |

## 🔐 Зберігання конфігурації

Конфіг (API-ключ, токен використання, мова, автозапуск тощо) зберігається у `config.json` в каталозі даних користувача:

- **Windows**: `%APPDATA%/deepseek-monitor/config.json`
- **macOS**: `~/Library/Application Support/deepseek-monitor/config.json`
- **Linux**: `~/.config/deepseek-monitor/config.json`

> **Безпека**: API-ключ і токен використання шифруються через системний ключницю (`safeStorage`) у Windows і macOS. У Linux без keyring вони зберігаються у відкритому вигляді.

## 📝 Примітки

1. **Термін дії токена використання** — токени, отримані через веб-вхід, можуть спливати; синхронізуйте знову, якщо запити використання не працюють
2. **Баланс і використання** — баланс запитується за API-ключем; статистика використання — за окремим токеном
3. **Кілька валют** — витрати показуються за кожною валютою (напр. `¥12.45 + $0.76`) і ніколи не конвертуються та не додаються
4. **Усі ключі типово** — вибір у картці балансу починається з «Усі ключі»; перемкніться на окремий ключ, щоб обмежити показники
5. **Автозапуск Windows** — через ключ реєстру `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
6. **Автозапуск macOS** — через `~/Library/LaunchAgents/com.deepseek.monitor.plist`
